# SuiFoot brand kit

## Logo
- `logo-mark.svg` is the master mark: an angular hexagon shield (gold rim, navy core, cyan inner line) with a football and a white drop. Also used as the favicon.
- Light backgrounds: `wordmark-light.png` (transparent, navy "SUI"), `wordmark-on-white.png`, `lockup-light.png`. Never use the white-text versions on white.
- PNG exports: `logo-mark-1024.png` (transparent), `x-profile-400.png` (X/Twitter avatar), `x-banner-1500x500.png` (X header), `lockup-dark.png`, `wordmark.png` (transparent), `social-1200x630.png` (link preview / Open Graph).
- Keep clear space of at least 1/4 of the mark's width around it. Do not recolour the mark, stretch it or add other effects. Put it on navy or white backgrounds.

## Wordmark
"SUIFOOT", uppercase, skewed 8 degrees to the left, Orbitron Black with wide tracking (0.1em). "SUI" in white (or navy on light backgrounds), "FOOT" in the gold gradient.
`wordmark.svg` uses live text, so it needs Orbitron installed; use `wordmark.png` when in doubt.

## Typography
- Display (name, big titles, scores): Orbitron 900 (variable, 400-900).
- Headings, tables, buttons, taglines: Rajdhani 600/700, uppercase with letter-spacing .06-.3em.
- Body text: Inter (system sans as fallback).
- Fonts are in `fonts/` (SIL Open Font License, free to use and embed).

## Colours
| Role | Value |
|---|---|
| Sui blue (ball, accents) | `#4DA2FF` |
| Cyan glow | `#38bdf8` |
| Navy core | `#0f1a52` to `#070b24` |
| Ball outline navy | `#071238` |
| Gold light / main / dark | `#fbe9a6` / `#d9a521` / `#8a5d0a` |
| Gold gradient | `linear-gradient(135deg, #fbe9a6, #d9a521 55%, #9a6d12)` |
| Text on dark | `#ffffff`, secondary `#9fb3d9` |

In the game, the ambient colour (header, highlights) follows the coached club's badge colour; logo, fonts and gold stay fixed.

## Tagline
"The football manager for the Sui ecosystem"

## Notes
The drop is a generic shape, not the official Sui logo. Check Sui's brand guidelines before using their marks, and before using the name "SuiFoot" commercially.
